# Пробный сборщик Bugaga

PHP 8.1+ с расширениями curl и dom. Без Composer и сторонних библиотек.

Проверка осуществимости на реальном bugaga.ru прошла: получена лента и три подборки, извлечены оригинальные изображения и даты публикации, скачаны пять изображений. Сборщик выбирает изображения только из articleBody; миниатюры заменяет оригиналом из ссылки, рекламные блоки и рекомендации исключает. Это пробный сборщик, не готовый сервис: обход архива, MySQL и регулярное обновление ещё не реализованы.

Из корня проекта на вашем сервере:

```sh
php tests/parser.php
php bin/probe.php
```

В текущей облачной среде PHP установлен локально; вместо `php` используйте `/workspace/php-runtime/php`.

Скрипт проверяет первые три найденных поста и скачивает до пяти уникальных изображений. Между запросами пауза в одну секунду. HTML страниц, картинки и отчёт с адресами, датами публикаций, размерами и SHA-256 сохраняются в `var/probe/`. Дата публикации сохраняется как указана источником, без предположения о часовом поясе. Повторный запуск не перезаписывает существующие изображения с тем же хешем. Ошибки сети, HTTP, парсинга и проверки картинок возвращают ненулевой код завершения. TLS-проверка включена. Ссылки и перенаправления разрешены только на HTTPS bugaga.ru и www.bugaga.ru.

Запускайте из CLI, вне публичного каталога сайта. MySQL и cron для разовой проверки не нужны. Подключение к cron имеет смысл после добавления постоянного хранения и инкрементального обновления.
